# LocalDesk v0.2.0-beta.1

状态：待签名与公证，尚未发布二进制安装包。

## 亮点

- 发现本机摄像头、鼠标和键盘
- 枚举、写入并回读摄像头公开的 CoreMediaIO 控制项
- 配置鼠标中键与侧键映射，并可随时暂停
- 根据前台应用自动切换设备配置
- 首次启动引导、权限中心、诊断报告和 About 页面
- 本地配置导入导出、日志轮转和损坏配置恢复

## 系统要求

- macOS 13 或更高版本
- Apple Silicon 或 Intel Mac（Universal Binary）

## 隐私与权限

LocalDesk 不包含账号、云同步、遥测或广告。摄像头、输入监控和辅助功能权限均可跳过，并可稍后在权限中心配置。

## 已知限制

- 可调摄像头参数完全取决于设备实际公开的能力；部分内置摄像头可能没有可调项。
- 首个公开 DMG 必须先完成 Developer ID 签名、Apple 公证和干净 Mac 安装验证。
